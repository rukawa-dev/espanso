# Espanso 설정 프로젝트

이 프로젝트는 [Espanso](https://espanso.org/) 텍스트 확장기(Text Expander)를 위한 사용자 정의 설정 및 스니펫 모음입니다.

## 주요 기능

- **자동 텍스트 확장**: 자주 사용하는 문구나 명령어를 짧은 키워드로 대체합니다.
- **동적 스니펫**: 쉘 스크립트 등을 이용해 동적인 값을 생성합니다.
  - `::uid`: 8자리 무작위 16진수 문자열을 생성합니다. (예: `a30768ef`)
  - `::ㅕㅑㅇ`: 한글 입력 상태에서도 `::uid`와 동일하게 8자리 무작위 16진수 문자열을 생성합니다.

## 디렉토리 구조

- `config/`: Espanso의 전역 및 애플리케이션별 설정 파일이 포함되어 있습니다.
- `match/`: 텍스트 확장 규칙(스니펫)이 정의된 YAML 파일들이 포함되어 있습니다.

## 사용 방법

1. Espanso가 설치되어 있어야 합니다.
2. 이 저장소의 파일들을 Espanso 설정 디렉토리(`~/Library/Application Support/espanso` 등)에 복사합니다.
3. Espanso가 변경 사항을 감지하고 자동으로 재시작됩니다.
